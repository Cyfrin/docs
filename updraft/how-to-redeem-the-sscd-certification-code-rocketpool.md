## Overview

Cyfrin Updraft has partnered with Rocket Pool to provide "SSCD+ certification vouchers to the first 25 students who complete the Rocket Pool course."

## Redemption Steps

### 1. Join the Rocket Pool Discord Server

Click the green "Join Discord" button and follow the prompts to access the Rocket Pool server.

### 2. Contact the Verification Admin

Once in the server, send a direct message to **ShfRyn** (User ID: 152043366719160320) with your Cyfrin account email address.

**Important:** Verify you're contacting the correct person before messaging. See verification instructions below.

### Eligibility Requirements

Before issuing vouchers, the teams will verify:

- Completion of all course lessons
- Quiz score assessment
- Request authenticity

"The Rocket Pool and Cyfrin Updraft teams reserve the right to reject any voucher request that fails to meet these requirements."

## Verification Process

1. ShfRyn validates your eligibility
2. Upon approval, you receive your certification code

## How to Verify User ID

To confirm you're contacting the right ShfRyn:

1. Search for ShfRyn in Rocket Pool Discord
2. Click their profile
3. Select "Copy User ID" from the menu
4. Confirm the ID matches: **152043366719160320**
